## 지켜야 할 규칙 (매 세션 먼저 읽기)
짧은 행동 규칙으로 쓴다. 근거는 아래 표에 둔다.
1. (예) 원본 데이터와 개인정보 컬럼은 저장소에 커밋하지 않는다. `.gitignore`에 포함한다.
2. (예) 이름·연락처·주민번호는 분석 전에 삭제하거나 가명처리한다. 재식별 시도는 하지 않는다.
3. (예) 데이터를 외부 API/LLM에 보내기 전에 개인정보 포함 여부를 확인하고, 포함이면 사용자에게 먼저 묻는다.
4. (예) A사이트 데이터는 약관상 자동 수집 금지이므로 크롤링하지 않고 공식 API를 쓴다.
5. (예) 결과 공개 전, 소수 집단이 식별될 수 있는지 확인한다. 집계 셀 건수가 N 미만이면 합치거나 숨긴다(N: ___).
6. (예) 외부 LLM에는 집계·요약만 보내고 행 단위 원본은 보내지 않는다.
