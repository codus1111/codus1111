# 한국 법령 후보 지도 (데이터 분석 프로젝트용)

이 문서는 **조사의 출발점**이다. 조문 번호와 내용은 개정되므로 반드시 국가법령정보센터(law.go.kr)의 현행 원문으로 재확인하고, 확인 날짜를 COMPLIANCE.md에 남긴다. 아래 조문 번호는 기억에 기반한 힌트이며 틀릴 수 있다.

## 목차
1. 상황별 빠른 선택표
2. 개인정보보호법
3. 신용정보·위치정보·기타 개인 관련 법
4. 수집·크롤링·저작권 관련
5. 외부 서비스·LLM·국외 이전
6. 공개·판매·공유할 때
7. 해외 법 (해당 시)
8. 조사 팁

## 1. 상황별 빠른 선택표

| 상황 | 먼저 볼 것 |
|---|---|
| 이름·연락처·ID·IP·영상 등 개인정보가 데이터에 있음 | 개인정보보호법 (수집·이용 근거, 목적 외 이용, 안전조치) |
| 건강·사상·생체·범죄경력 등 민감정보, 주민번호 등 고유식별정보 | 개인정보보호법 민감정보·고유식별정보 규정 (원칙적 별도 동의·강한 제한) |
| 통계·연구 목적으로 개인정보 활용 | 개인정보보호법 가명정보 특례, 가명처리 및 결합 절차, 재식별 금지 |
| 금융·신용·결제 데이터 | 신용정보의 이용 및 보호에 관한 법률 |
| 위치 데이터 | 위치정보의 보호 및 이용 등에 관한 법률 |
| 웹 크롤링·스크래핑 | 대상 사이트 이용약관·robots.txt, 저작권법(데이터베이스제작자 권리), 정보통신망법, 부정경쟁방지법, 형법상 업무방해 등 |
| 공공데이터 | 공공데이터법, 공공누리 등 이용조건 표시 |
| 설문·인터뷰 | 개인정보보호법 동의, 생명윤리법(인간 대상 연구인 경우 IRB) |
| 데이터 구매·거래 | 데이터 이용 계약·라이선스, 데이터산업법 |
| AI·LLM 학습/입력에 사용 | 개인정보보호법, 저작권법(복제·공정이용), 서비스 약관의 학습 조항 |

## 2. 개인정보보호법 (핵심 체크)

- **수집·이용 근거**: 정보주체 동의 또는 법정 근거가 있는가. 최소 수집 원칙.
- **목적 외 이용·제3자 제공**: 수집 목적 범위 안인가. 분석 목적이 원래 고지 목적과 합리적으로 관련되는가.
- **민감정보·고유식별정보**: 별도 동의나 법적 근거 없이 처리하지 않는다.
- **가명정보**: 통계작성·과학적 연구·공익적 기록보존 목적에 한해 동의 없이 처리 가능. 추가정보 분리 보관, 서로 다른 처리자 간 결합은 지정 전문기관을 통해서만, **재식별 시도 금지**.
- **안전조치**: 접근통제, 암호화, 접속기록 보관.
- **보유기간·파기**: 목적 달성 시 지체 없이 파기.
- **유출 시 통지·신고** 의무.
- **국외 이전**: 해외 클라우드·해외 서비스로 보낼 때의 요건.
- 개인정보 처리자로서 고지 사항(개인정보 처리방침 등).

## 3. 기타 개인 관련 법

- 신용정보법: 개인신용정보 처리·결합·가명처리 별도 규율.
- 위치정보법: 개인위치정보 수집·이용·제공 동의, 사업 허가·신고.
- 정보통신망법: 이용자 개인정보 보호 일부 규정, 정보통신망 침해·비밀침해 금지.
- 생명윤리 및 안전에 관한 법률: 인간 대상 연구, 유전자·건강 정보.
- 통신비밀보호법: 대화·통신 내용 수집.

## 4. 수집·크롤링·저작권

- 이용약관/robots.txt가 자동 수집을 금지하는가. 로그인 뒤 데이터는 더 위험.
- 서버에 과도한 부하를 주는 수집은 업무방해 등으로 문제 될 수 있다.
- 저작권법: 데이터베이스제작자의 권리, 복제·전송, 공정이용 판단(목적·성격, 이용 정도, 시장 영향).
- 텍스트·이미지 등 저작물을 모델 학습·분석에 쓸 때 별도 검토.
- 부정경쟁방지법: 타인의 투자·노력으로 만든 데이터의 무단 사용.
- 유료·라이선스 데이터셋: 재배포·상업 이용·파생물 조건.

## 5. 외부 서비스·LLM·국외 이전

- 개인정보가 든 데이터를 외부 API나 LLM에 입력하기 전에: 개인정보 위탁/제3자 제공/국외 이전 해당 여부, 서비스 약관의 데이터 보관·학습 사용 조항.
- 가능하면 가명·익명 처리 후 입력, 불가피하면 위탁 계약과 고지 확인.
- 사내 데이터 보안 규정과 영업비밀(부정경쟁방지법) 확인.

## 6. 공개·판매·공유할 때

- 결과물에 개인을 식별할 수 있는 정보(소수 집단, 희귀 조합, 위치+시간)가 남지 않는지 확인. 소수 셀 집계 문제.
- 공개 데이터셋 배포 시 원본 라이선스의 재배포·상업 조건.
- 논문·보고서 게재 시 출처 표시와 인용.
- 결과를 광고·마케팅에 쓰면 표시광고법, 개인정보 마케팅 동의.

## 7. 해외 법 (해당 시)

- EU/영국 이용자: GDPR (적법 근거, 정보주체 권리, 국외이전 메커니즘, DPIA).
- 미국: 캘리포니아 CCPA/CPRA, 아동 관련 COPPA, 주별 법.
- 중국: 개인정보보호법(PIPL), 데이터보안법.
- 일본: 개인정보보호법(APPI).
- 해당 국가의 최신 공식 자료(감독기관 사이트)를 직접 확인한다. 한국 법과 다른 점 중심으로 COMPLIANCE.md에 기록.

## 8. 조사 팁

- law.go.kr에서 법령명으로 검색해 현행 조문을 읽는다. 시행일과 최근 개정일을 확인한다.
- 개인정보보호위원회(PIPC) 가이드라인(가명정보 처리 가이드라인 등)이 실무 기준이 되므로 함께 확인한다.
- 약관은 날짜가 바뀌므로 확인 날짜를 기록하고, 주요 문구 위치(조항 번호)를 남긴다.
- 확신이 없는 판단은 🟡로 두고 전문가 확인을 권한다.
