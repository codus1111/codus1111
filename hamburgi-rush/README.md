# 🍔 햄부기 러시 (Hamburgi Rush)

> 패스트푸드 매장 알바 2년 7개월의 기억으로 만든 도트 피크타임 게임

**▶ 바로 플레이:** https://codus1111.github.io/codus1111/hamburgi-rush/ (PC · 모바일)

## 어떤 게임인가요
점심 피크, 매장 손님과 배달 주문이 동시에 몰려옵니다. 주방에서 메뉴를 담아 전달하고, 중간중간 터지는 **품절**에 맞춰 **키오스크와 배달앱의 메뉴 노출을 바로 꺼야** 합니다.
실제 매장에서 판매 종료나 품절 메뉴가 키오스크에 남아 주문이 들어오던 경험을 게임 규칙으로 옮겼습니다.

### 게임 규칙
- **60초** 한 판. 시작 전 3·2·1 카운트다운
- 주방에서 메뉴를 담고 **전달**하면 쟁반과 똑같은 주문(매장 또는 배달)으로 자동 전달
- 품절이 나면 **키오스크와 배달앱 둘 다 OFF**, 이미 들어온 품절 주문은 **품절 메뉴 취소**
- 🔥 **러시 모드:** 5연속 완료 시 6초 동안 점수 ×2
- 💢 **클레임:** 매장 손님 이탈 또는 배달 지연 → 3건이면 영업 종료
- 결과 화면에 **품절 → 채널 OFF까지 걸린 시간**을 운영 지표처럼 보여 줌

### 기능
- 🎓 **선택형 튜토리얼** (5단계 연습 모드, 시간 제한 없음)
- 🌐 **전체 랭킹 TOP 5** (Supabase). 한 사람당 최고 점수 하나, 같은 닉네임은 #태그로 구분
- 🪙 **코인**(100점 = 1개)과 🛍 **상점**: 알바생 옷 6종, 매장 인테리어 6종
- ☁ **구글 로그인(선택)**: 코인·스킨·닉네임을 계정에 저장해 기기를 바꿔도 이어 하기 (Firebase)
- ⚙ **환경설정**(계정, 닉네임, 배경음악·효과음), ⏸ **일시정지**(Esc / P, 탭 전환 시 자동)
- 🎵 직접 작곡한 칩튠 배경음악과 효과음 (Web Audio로 합성, 외부 음원 없음)
- 🖥 PC는 화면 비율에 맞춰 매장이 가로로 넓어지고, 📱 모바일은 한 화면에 맞춤
- 📊 Microsoft Clarity로 플레이 데이터(시작·종료 이유·점수대·러시 등) 수집

## 조작
| | PC | 모바일 |
|---|---|---|
| 메뉴 담기 | 1~6 | 메뉴 탭 |
| 전달 | Space / Enter | 전달 버튼 |
| 품절 메뉴 취소 | Q | 품절 메뉴 취소 버튼 |
| 쟁반 비우기 | X | 비우기 버튼 |
| 일시정지 | Esc / P | ⏸ 버튼 |
