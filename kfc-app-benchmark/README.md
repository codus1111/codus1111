# KFC 앱 기능 비교

**KFC 앱을 경쟁 버거 3곳(맘스터치·버거킹·롯데리아) 앱과 비교해, KFC 앱에 없는 기능을 찾고 개선안을 낸 MVP**

수업 "매일 손으로 하던 조사를 AI 에이전트로 줄이는 MVP"에서 만든 결과물입니다. 지원하려는 KFC IT팀(채널별 메뉴·상품정보 정합성 점검) 업무와, 롯데리아 매장 아르바이트 2년 7개월 동안 겪은 문제(팔지 않는 신메뉴 주문, 품절 메뉴 기프티콘 주문)에서 출발했습니다.

**[비교 화면 바로 보기](https://codus1111.github.io/codus1111/kfc-app-benchmark/mvp.html)**

## 결과 한눈에

| 비교한 줄 | 경쟁사에 있고 KFC에서 못 찾은 기능 | KFC 앱 이용자 (월평균) |
| :---: | :---: | :---: |
| 88줄 (4곳, 기능 24가지) | **3개** · 재주문, 쿠폰 고르기, 주문 평점 | **119만 명** · 2024년 63만 명에서 약 1.9배 |

- **개선안 1 · 로그인 막힘 없애기:** 2026-11부터 회원만 주문할 수 있는데, 앱 리뷰의 대표 불만이 가입·로그인·인증번호·비밀번호 찾기예요. 볼 숫자는 로그인 성공률입니다.
- **개선안 3 · 메뉴·품절 정보 채널 맞추기:** 앱·홈페이지·배달앱·기프티콘에서 같은 메뉴 정보가 보이게 해요. 롯데리아 매장 경험과 KFC IT팀 공고의 정합성 점검 업무에서 나왔어요.
- **개선안 2 · 장바구니 쿠폰 추천:** 가진 쿠폰을 버리지 않게, 장바구니에서 가장 이득인 쿠폰과 곧 만료·조건 없는 쿠폰을 먼저 보여 줘요. 목표는 재방문율입니다. 화면 안에 예시 데이터로 체험해 볼 수 있는 장바구니가 있어요.

## 조사 기준과 한계

- 조사일은 2026-11-16, 근거 자료 날짜는 2024-06 ~ 2026-11입니다.
- 공개 자료(공식 홈페이지, App Store·Google Play, 기사)만 썼어요. 앱 안 화면은 로그인해야 보여서 "못 찾음"이 20칸 남아 있어요. 못 찾음은 "없다"가 아니라 "모른다"는 뜻입니다.
- 매출은 2025년 운영사 기준입니다. 롯데리아는 단독 매출이 공개되지 않아 롯데GRS 매출에 롯데리아 비중 약 70%(보도)를 곱한 추정치예요. 롯데리아 앱 이용자 수는 롯데잇츠 통합 앱 기준입니다.
- 앱 화면 이미지는 각 회사가 App Store에 올린 미리보기를 원래 주소에서 불러와요. 저작권은 각 회사에 있습니다.
- 장바구니 체험의 메뉴·가격·쿠폰은 예시이며 실제 KFC 값이 아닙니다.

<sub>HTML · CSS · JavaScript · Claude Code<br>공개 자료로 만든 학습용 MVP이며, KFC·맘스터치·버거킹·롯데리아와 관계없습니다. 상표와 서비스 이름은 각 소유자의 것입니다.</sub>
