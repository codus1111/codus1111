개선안 1 · 앱 기본기: 로그인 막힘 없애기

먼저 고칠 것
운영 방침

쿠폰과 추천보다 먼저, 앱을 연 고객이 막히지 않고 주문을 끝내게 한다. 이제 회원만 주문할 수 있어서 로그인이 곧 주문의 입구다.

  • 가입·로그인 단계 줄이기 · 간편 로그인을 더하고, 인증번호가 안 오면 다시 받기·다른 방법을 바로 보여 주기
  • 아이디·비밀번호 찾기 고치기 · 리뷰에서 가장 많이 나온 불만
  • 로그인해도 장바구니 그대로 · 메뉴를 담다가 로그인하러 가도 담은 메뉴가 사라지지 않게

볼 숫자로그인 성공률 로그인을 시도한 사람 중 성공한 비율

근거와 같이 볼 숫자
  • 평점이 가장 낮은 축: KFC 앱 평점은 아이폰 1.7점, 안드로이드 2.1점. 버거킹(3.8점, 4.2점)과 차이가 커요 (2026-11-16 확인).
  • 리뷰 대표 불만: 회원가입·로그인·인증번호·비밀번호 찾기가 잘 안 된다 (App Store 리뷰 요약, 2025-04 리뷰 등).
  • 간편 로그인 없음: 2026-11-16 KFC 홈페이지 로그인 화면을 직접 열어 보니 아이디·비밀번호 로그인만 있고 카카오·네이버 같은 간편 로그인과 비회원 주문 버튼이 없어요 (앱 화면은 다를 수 있음).
  • 로그인이 더 중요해짐: 2026-11부터 앱·홈페이지 비회원 주문을 막고 회원만 주문받아요 (뉴시스 2026-11-11).
  • 회사도 개편을 계획: 노후화된 앱을 전면 개편할 계획이라고 밝힌 적 있어요 (뉴스탭 2025-05-08).
  • 업계 공통 문제: 버거킹 리뷰의 대표 불만도 로그인·간편가입 연동 오류예요. 먼저 고치면 차이를 만들 수 있어요.

같이 볼 숫자: 가입 완료율, 인증번호 도착률, 비밀번호 찾기 성공률, 로그인 화면에서 앱을 닫은 비율, 리뷰 중 로그인 불만 비율, 앱 평점

주문까지 막히는 곳리뷰에서 나온 불만을 주문 순서에 놓아 봤어요
  1. 앱 열기메뉴 보기
  2. 메뉴 담기장바구니
  3. 로그인 · 회원가입인증번호가 안 와요 · 비밀번호를 못 찾아요
  4. 결제쿠폰 · 선불카드
  5. 주문 완료징거벨오더 · 딜리버리

비회원 주문이 막힌 뒤로는 3번에서 막히면 주문 자체가 끝나요. 개선안 2(쿠폰 추천)도 3번을 지나야 효과가 나요.

개선안 2 · 장바구니 쿠폰 추천

목표: 재방문율 높이기
운영 방침

한 번 주문한 고객이 다시 주문하게 만든다. 가진 쿠폰을 버리지 않게 돕고, 주문 뒤 다음 주문 쿠폰을 보여 준다.

  • 가장 이득인 쿠폰 먼저 · 지금 장바구니에 쓸 수 있는 쿠폰을 할인 금액 순으로
  • 곧 만료 · 조건 없음 표시 · 못 쓰는 쿠폰은 "○○원 더 담으면 사용 가능"
  • 주문 뒤 다음 쿠폰 · 만료 3일 전에 푸시로 한 번 알림

볼 숫자재방문율 첫 주문 뒤 30일 안에 다시 주문한 회원 비율

지금 KFC·경쟁 3곳 앱에서 이 기능은 공개 자료로 못 찾았어요. 버거킹만 등급 쿠폰을 고객이 직접 고르게 해요.

자세한 규칙과 확인 근거

왜: 사람들 의견은 "쿠폰을 많이 주면 좋겠다", "어떤 쿠폰이 제일 이득인지, 지금 써야 하는 쿠폰이 뭔지 보여 주면 좋겠다"였어요.

  1. 지금 쓸 수 있는 쿠폰만 위에 보여 준다. 주문 방식(징거벨오더·딜리버리), 최소 주문 금액, 대상 메뉴를 모두 맞춘 쿠폰이다.
  2. 할인 금액이 큰 순서로 놓고, 맨 위 쿠폰에 "가장 이득"을 붙인다. 할인율도 같이 보여 준다.
  3. 할인 금액이 같으면 만료가 빠른 쿠폰을 먼저. 7일 안에 끝나면 "곧 만료"를 붙인다.
  4. 최소 주문 금액이 없는 쿠폰에는 "조건 없음"을 붙인다.
  5. 못 쓰는 쿠폰은 아래로 내리고 이유를 적는다. 금액이 모자라면 "○○원 더 담으면 사용 가능"으로 알려 준다.
  6. 한 주문에 쿠폰은 1장만 쓴다. KFC는 쿠폰 중복 사용을 막아 두었다는 보도(2025-03)를 따른다.
  7. 주문이 끝나면 다음 주문에 쓸 수 있는 쿠폰과 만료일을 보여 주고, 만료 3일 전에 푸시로 한 번 알린다.
지금 있는 기능인가 (2026-11-16 확인)
  • KFC: 가입·등급·생일 쿠폰과 푸시 알림은 있음. 장바구니에서 가장 이득인 쿠폰을 골라 주거나 만료 임박 쿠폰을 따로 보여 주는 기능은 공개 자료에서 못 찾음.
  • 경쟁 3곳: 쿠폰 자동 지급은 있지만 장바구니 최적 쿠폰 추천은 못 찾음. 버거킹은 등급 쿠폰을 고객이 직접 고르는 마이픽이 있음 (EBN 2025-12).
  • 쿠폰 중복: 롯데리아는 2025-04부터 롯데잇츠에서 주문 1건에 할인 쿠폰 5장까지 중복 사용. 맥도날드·버거킹·맘스터치·KFC는 중복 사용을 막아 둠 (국민일보 2025-03-30).

앱 안 화면은 로그인해야 보여서, 실제 앱에 비슷한 기능이 있는지는 직접 열어 확인이 필요해요.

같이 볼 숫자: 추천 쿠폰을 고른 비율, 쿠폰 사용률, 쓰지 못하고 사라진 쿠폰 수, 쿠폰 때문에 더 담은 금액

체험해 보기메뉴·가격·쿠폰은 모두 예시예요 (가정, 실제 KFC 값 아님)
공개 자료로 만든 학습용 MVP(Minimum Viable Product)이며, 조사한 회사와 관계없습니다.
