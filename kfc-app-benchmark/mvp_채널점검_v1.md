# mvp.md · KFC 채널별 메뉴 정보 점검

> 표시 규칙: **(가정)**은 아직 확인하지 않고 짐작으로 적은 곳이에요. 확인하면 표시를 지우거나 고쳐요.

## 1. 한 줄 요약
KFC 메뉴 정보(메뉴명, 가격, 옵션, 판매 상태)가 고객이 보는 채널마다 같은지 매일 확인하고, 어긋난 곳을 한 화면에 모아 보여 준다.

## 2. 왜 이 조사인가
롯데리아 매장에서 2년 7개월 동안 일하면서 세 가지 문제를 반복해서 겪었다.

1. 우리 매장에서 판매하지 않는 신메뉴가 키오스크에 반영되어 고객 주문이 들어왔다.
2. 매장에서 품절 처리한 제품이 기프티콘 주문으로는 계속 들어왔다.
3. 이미 판매가 중단된 메뉴가 키오스크와 POS에 많이 남아 있어 화면을 보기 불편했다.

세 문제 모두 한 곳에서 바꾼 메뉴 정보가 다른 채널에 똑같이 반영되지 않거나, 판매가 끝난 메뉴가 제때 정리되지 않아서 생긴다. 이런 불일치는 대부분 고객이 주문한 뒤에야 드러난다. 그때마다 매장에서 고객에게 상황을 설명하고, 다른 메뉴로 다시 주문을 받은 뒤 가격 차이만큼 환불해야 했다.

이 조사로 모든 오류를 막을 수는 없다. 하지만 메뉴 정보가 채널마다 같은지, 판매 종료된 메뉴가 남아 있지 않은지 매일 확인해서 **이런 문제가 생기는 일을 줄이는 것**을 목표로 한다.

## 3. 누가 이 화면을 보고 무엇을 결정하나
- 보는 사람: KFC IT팀 상품정보 담당자 **(가정: 공고 담당업무를 보고 정함)**
- 결정하는 것: 오늘 어느 채널의 어떤 메뉴 정보를 먼저 고칠지

## 4. 조사 대상 (메뉴)
10~20개로 시작한다.
- 신메뉴, 진행 중인 프로모션 메뉴 **(가정: 실제 메뉴명은 KFC 공식 홈페이지에서 확인 필요)**
- 최근 판매 종료된 메뉴 **(가정: 종료 공지를 어디서 확인할지 아직 모름)**
- 기본 메뉴 몇 개 (비교 기준용)

## 5. 채널
| 채널 | 확인 방법 | 비고 |
|---|---|---|
| KFC 공식 홈페이지 | 직접 보고 옮겨 적기 | 기준 채널로 삼는다 **(가정)** |
| KFC 앱 | 직접 보고 옮겨 적기 | 매장 선택에 따라 메뉴가 다를 수 있음 **(가정)** |
| 배달앱 1~2곳 | 직접 보고 옮겨 적기 | 자동 수집은 약관 확인 전까지 하지 않음 |
| 기프티콘·모바일 교환권 판매처 | 직접 보고 옮겨 적기 | 품절 사례와 직접 연결되는 채널 |

## 8. 범위와 한계
- 매장 안 키오스크와 POS 데이터는 바깥에서 볼 수 없다. 이 조사는 고객이 볼 수 있는 채널끼리만 비교한다.
- 직접 보고 옮겨 적으므로 하루에 다루는 메뉴 수가 적다.
- 앱과 배달앱은 매장이나 지역에 따라 다르게 보일 수 있다. 매일 같은 매장·주소 기준으로 확인한다. **(가정: 기준 매장 아직 안 정함)**
