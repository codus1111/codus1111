# 솔트웨어 인사이트 블로그 콘텐츠 제작 (AI 에이전트 4개 연결)

> **개인 학습 프로젝트입니다.** CJ올리브네트웍스 L.L.M Academy 교육 중 만들었습니다. 솔트웨어와 협업하거나 제휴한 프로젝트가 아니며 공식 사이트도 아닙니다. 솔트웨어의 공개 자료를 바탕으로, AI 에이전트로 콘텐츠를 만드는 과정을 연습한 결과물입니다.

## 한눈에 보기

| 항목 | 내용 |
|---|---|
| 목적 | 공개된 기업 자료를 바탕으로, 조사부터 글쓰기·이미지·최종 조립까지 이어지는 콘텐츠 제작 과정을 AI 에이전트로 구성해 본다 |
| 결과물 | 블로그 글 12편 (데이터 한 스푼 3편, 데이터 노트 4편, 고객 사례 5편)과 이를 보여 주는 사이트 화면 |
| 에이전트 | 4개: researcher → writer → image-maker → assembler |
| 자료 | 솔트웨어 공개 자료(홈페이지, 공식 유튜브 영상, 기술 블로그), 공개 기술 문서와 정부 자료 |
| 도구 | Claude(에이전트 실행), Python과 HTML/CSS(이미지·사이트 생성) |
| 시기 | 2026.11 |

## 제작 과정

```
주제 → researcher → writer → image-maker → assembler → 글 + 사이트
         (조사)      (초안)     (이미지)       (조립)
```

| 에이전트 | 하는 일 | 입력 | 출력 |
|---|---|---|---|
| researcher | 주제를 조사해 사실과 출처 URL을 정리 | 주제 | `research.md` |
| writer | 조사 자료와 스타일·SEO 가이드를 읽고 초안 작성 | `research.md`, `guide/*` | `draft.md` |
| image-maker | 초안의 이미지 자리를 HTML·CSS로 그려 PNG로 캡처 | `draft.md`, `guide/image-guide.md` | `images/*.png` |
| assembler | 글과 이미지를 합쳐 최종본과 사이트를 생성 | `draft.md`, `images/` | `final.md`, 사이트 |

에이전트 정의는 [`.claude/agents/`](.claude/agents/), 전체 규칙은 [`CLAUDE.md`](CLAUDE.md)에 있습니다.

## 지킨 제작 규칙

1. 솔트웨어에 관한 사실은 솔트웨어 공개 자료에서 확인한 것만 쓴다.
2. 수집한 사실은 지식 파일([`guide/saltware-knowledge.md`](guide/saltware-knowledge.md))로 정리해 에이전트가 참고하게 한다. 솔트웨어 공식 유튜브 영상 링크를 AI에 주어 영상 내용을 읽고 정리하게 한 것이 바탕이다.
3. 지식 파일에 있는 사실을 바탕으로 쓰고, 근거 없는 숫자나 사례는 지어내지 않는다. 확인되지 않는 부분은 "공개되지 않았다"고 쓰거나 비워 둔다.
4. 글에 쓴 정보의 출처를 글 끝에 남긴다.
5. 일반 기술 설명은 공식 문서와 정부 자료를 우선한다.
6. 이미지는 외부 이미지 생성 서비스나 외부 로고·썸네일을 쓰지 않고, 직접 HTML·CSS로 그려 캡처한다.
7. 글쓰기 규칙은 [`guide/style-guide.md`](guide/style-guide.md), SEO 규칙은 [`guide/seo-guide.md`](guide/seo-guide.md), 이미지 규칙은 [`guide/image-guide.md`](guide/image-guide.md)에 있다.

"원문 대조"는 2026-11-12 공개 전 점검에서 글의 사실을 출처와 맞춰 본 결과입니다. 솔트웨어 홈페이지와 기술 블로그, 공식 유튜브 영상, Databricks·AWS 공식 문서와 발표를 기준으로 했습니다. 영상은 자동 생성된 한국어 자막(오인식이 있음)을 읽고 맞춰 보았습니다. 금융위원회 보도자료는 원문(2025.2.5)에서 "수범사항 293개 → 166개" 문구를 확인했습니다. 중소벤처기업부 조사 수치(제조데이터 수집 60.8%, 제조 AI 도입 0.1%)는 중기부 원문을 열지 못해 발표 내용을 전한 언론 보도(디지털데일리)로 확인했고, 글의 출처 링크도 그 기사로 바꿨습니다. 정보통신망법 제47조 조문은 국가법령정보센터 접속 오류로 원문을 열지 못했고, 법무법인·정부 해설 자료로만 확인했습니다. 비유와 조언 같은 설명 문장은 원문이 없어 대조 대상이 아닙니다.

## 내 역할과 AI의 역할

**내가 한 일**
* 프로젝트 방향 설정과 솔트웨어 공개 자료 선정
* 솔트웨어 공식 유튜브 영상 링크를 AI에 주어 영상 내용을 읽고 정리하게 해 지식 파일의 바탕을 마련
* 지식 파일의 사실만 쓰고, 근거 없는 정보를 넣지 않고, 출처를 표시하도록 하는 작성 규칙 설정
* 에이전트 4개를 연결해 조사부터 최종 조립까지 이어지는 제작 흐름 구성

**AI(Claude)가 한 일**
* 자료 조사, 글 초안 작성, 이미지 생성 스크립트와 사이트 생성 코드 작성

## 한계

* 솔트웨어에 관한 사실은 공개 자료를 정리한 것이며 내부 자료는 쓰지 않았습니다.
* 영상 자막은 자동 생성이라 오인식이 있어 핵심 주장만 맞춰 보았고, 문장 하나하나를 대조한 것은 아닙니다.
* 고객 사례에서 원문에 효과 수치가 없는 경우 수치를 쓰지 않았습니다.
* 백패커 글의 "2022년" 소제목은 솔트웨어 홈페이지에 전환 연도가 적혀 있지 않아, 관련 기사 날짜(2022.10)로 짐작한 것입니다. 확정된 연도가 아닙니다.
* 문의하기·구독 폼은 연습용 화면이며 어디로도 전송되지 않습니다.

## 고지

* 솔트웨어와 무관한 개인 학습 프로젝트이며, 솔트웨어의 공식 입장이 아닙니다.
* 회사명, 서비스명, 고객사 이름은 각 소유자의 것입니다.
* 글에 쓴 사실의 출처는 각 글 끝에 있습니다. 오류를 발견하면 알려 주세요.
