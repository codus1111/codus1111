# 이미지 가이드

이미지는 외부 AI 이미지 API를 쓰지 않는다.
매번 HTML과 CSS로 그림을 만들고 `scripts/capture.py`로 PNG로 캡처한다.

```
py -3 scripts/capture.py <html 파일> <png 파일> <가로> <세로>
```

## 1. 공통 규칙

- 블로그는 어두운 테크 매거진 디자인이다. 솔트웨어 로고(오렌지 점 4개 + saltware)와 오렌지만 브랜드에서 가져온다. 베이지는 쓰지 않는다
- 도표 이미지는 어두운 바탕에 흰 글씨, 강조는 오렌지 한 가지
- 색은 아래만 쓴다

| 이름 | 색 | 쓰임 |
|---|---|---|
| 숯색 | #141414 | 도표 바탕 |
| 카드 | #1E1E1E | 카드 바탕 |
| 선 | #2E2E2E | 구분선 |
| 흰 글자 | #F5F5F5 / #EDEDED | 제목 / 본문 |
| 회색 글자 | #BDBDBD / #9A9A9A | 보조 글자 |
| 오렌지 | #F49F20 / #E8811A | 강조 (한 장에 한두 군데만) |
| 연오렌지 | #2A1E10 | 강조 카드 바탕 |

- 글꼴: `'Pretendard', 'Malgun Gothic', sans-serif`
- 이미지 속 글자는 짧게. 한 줄에 15자 이내, 한 장에 문장 4개 이내
- 글자가 테두리 밖으로 나가거나 잘리면 안 된다
- 표지(썸네일)는 따로 만들지 않는다. 사이트가 글 머리말의 `cover` 단어로 글자 표지를 그린다

## 2. 썸네일

- 크기 1200 × 675
- 왼쪽 위에 시리즈명 배지 (먹색 바탕, 연오렌지 글자)
- 제목 위에 오렌지 막대 하나
- 가운데에 글 제목을 두 줄 이내로. 크게(56px 이상), 굵게
- 아래에 부제나 핵심 한 줄 (24px 안팎)

## 3. 본문 이미지 템플릿 4종

크기는 모두 1080 × 720.

| 템플릿 | 언제 쓰나 | 모양 |
|---|---|---|
| 비교표 | 두세 가지를 견줄 때 | 2~3열 카드. 열마다 제목 + 특징 3줄 |
| 단계 흐름도 | 순서가 있는 과정 | 동그란 번호 + 상자 3~4개가 가로로 이어짐 |
| 핵심 카드 | 꼭 기억할 것 3가지 | 세로로 쌓인 카드 3장. 카드마다 굵은 제목 + 한 줄 설명 |
| 강조 문구 | 글의 핵심 문장 하나 | 가운데 큰 따옴표와 문장 하나, 아래 작은 출처나 설명 |

## 4. 검수

캡처한 뒤 PNG를 직접 열어 보고 확인한다.
- 글자가 잘리거나 넘치지 않았는지
- 여백이 한쪽으로 쏠리지 않았는지
- 요소가 비뚤어지지 않았는지
문제가 있으면 HTML을 고쳐 다시 캡처한다. 문제가 없어질 때까지 반복한다.
