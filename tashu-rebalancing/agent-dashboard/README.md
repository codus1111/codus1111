# 에이전트 관제 대시보드

타슈 질의응답 에이전트(`src/agent.py`)가 일하는 모습을 보여 주는 화면입니다. 브라우저에서 `index.html`을 열면 됩니다(설치 없음).

- **Workflows**: 에이전트 루프가 질문을 도구에 나눠 맡기는 흐름(재생)
- **Traces**: 단계별로 몇 초 걸렸는지
- **Usage**: 시간·토큰, 저장소에 남은 기록(평가 질문 36개, 실험 10개, 조회 도구 4개 등)
- **Agents**: 역할 목록과 지키는 규칙
- **Q&A**: 평가 때 돌린 질문 36개와 에이전트의 실제 답(어떤 도구를 불렀는지, 자동 점검 결과 포함). 서버 없이 열려도 보입니다.

## 실제 기록과 시연용 수치를 구분합니다
- 화면 위쪽 칩이 **"시연용 수치"**이면 코드에 적어 둔 예시입니다(실제 측정값 아님).
- 실행 기록을 열면 칩이 **"실제 기록"**으로 바뀌고, 시간·토큰은 기록에서 계산한 값이 됩니다.
- "저장소에 남은 기록"의 숫자는 파일에서 센 값이고, 어느 파일인지 옆에 적었습니다.

## 쓰는 법
| 하고 싶은 것 | 방법 |
|---|---|
| 에이전트를 실행하며 기록 남기기 | `python src/agent.py "질문"` → `agent-dashboard/traces/`에 JSONL이 쌓임 |
| 실행하는 동안 실시간으로 보기 | `python agent-dashboard/serve.py`를 켜고 http://localhost:4173 열기 |
| 끝난 실행을 보기(서버 없이) | 대시보드 위쪽 **"실행 기록 열기"**로 `.jsonl` 파일 고르기 |
| 샘플로 보기 | **"실제 기록 샘플 보기"** (`samples/real-run-2026-11-11.jsonl`, 실제 실행 1회) |

Python만 있으면 됩니다(서버는 `http.server`). 서버는 내 컴퓨터(127.0.0.1)에서만 열립니다.

## Q&A 탭 데이터 (`src/make_qna.py`)
- `reports/agent_eval*.md`에 남은 실제 질문·답을 읽어 `qna.json`을 만들고 `index.html`에 끼워 넣습니다(`.venv/Scripts/python src/make_qna.py`).
- 대여소 이름(아파트·건물 등)은 "아파트 단지 3"처럼 유형+번호로 바꿉니다. 캠퍼스는 대학 이름을 그대로 씁니다. 바꾼 뒤에도 이름이 남으면 스크립트가 중단됩니다.
- 새 질문은 이 화면에서 할 수 없습니다. 내 컴퓨터에서 `python src/agent.py "질문"`으로 합니다.

## 기록에 남는 것과 안 남는 것 (`src/agent_trace.py`)
- 남김: 시각, 이벤트 종류, 도구 이름과 짧은 인자(구간·종류·개수·강수·기온·대여소 검색어), 걸린 시간, 토큰 수(Gemini 응답 값), 질문·답의 **길이**
- 안 남김: 질문과 답의 내용, 도구 결과, API 키, 내 컴퓨터의 전체 경로
- 기록 실패는 조용히 넘어가서 에이전트 동작을 막지 않습니다. 끄려면 `TASHU_TRACE=0`.
- `traces/`는 `.gitignore`에 들어 있습니다(내 실행 기록은 올리지 않음). 샘플만 `samples/`에 둡니다.

## 참고
화면 구조(탭, 노드 그림, 재생 방식)는 JIHOSW/jiho-agent 저장소의 관제 대시보드를 참고해 이 프로젝트에 맞게 고쳤습니다(참고 저장소에 라이선스 표기가 없어서 사용 허락을 따로 확인받았습니다). 기록 훅(Node.js) 대신 에이전트 코드가 직접 기록하는 방식으로 바꿨고, 서버도 Node 대신 Python으로 다시 썼습니다. 이 프로젝트에는 Claude Code 스킬이나 서브에이전트가 없어서, 단계는 `src/agent.py`, `src/eval_agent.py`, `CLAUDE.md`에 적힌 대로 옮겼습니다.
