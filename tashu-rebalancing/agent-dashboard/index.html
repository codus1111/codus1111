    누가 무엇을 맡나

    역할 이름은 이해를 돕기 위해 붙였습니다. 실제로는 Python 파일 하나(src/agent.py)가 Gemini에게 질문하고, 모델이 고른 함수 4개(src/agent_tools.py)를 실행합니다. 스킬이나 서브에이전트는 이 프로젝트에 없습니다.

    python src/agent.py "질문"사람 확인 없이 끝까지

    질문 → 모델이 도구 선택 → 도구 실행(집계 조회) → 결과 전달 → 답. 최대 6번 반복하고 호출 사이에 4초 쉽니다.

    python src/eval_agent.py읽어서 사람이 확인

    질문 세트를 한 번씩 돌려 도구 선택, 한계 고지, 출처, 순서 등을 자동으로 셉니다. 자동 점검이 못 잡는 것은 사람이 답을 읽어 찾습니다.

    역할하는 일읽는 것남기는 것

    지키는 규칙

    • ✓모델에는 대여소·시간대 집계 결과만 보냅니다. 원본 행과 자전거번호는 보내지 않습니다.
    • ✓이용이 적은 대여소는 숨기고, 개별 이동 경로는 다루지 않습니다.
    • !API 키는 .env에만 두고 사용자가 직접 넣습니다. 새 데이터·서비스는 약관을 확인하고 쓰기 전에 문서에 적습니다.
    • !커밋과 푸시는 사용자가 요청할 때만 합니다. 규칙이 애매하면 멈추고 사용자에게 묻습니다.

    실제 실행 기록 연결하기

    1. 1python src/agent.py "질문"을 실행하면 agent-dashboard/traces/에 시각·도구 이름·짧은 인자·걸린 시간·토큰을 한 줄씩 남깁니다. 질문과 답의 내용은 남기지 않고 길이만 남깁니다.
    2. 2실시간: python agent-dashboard/serve.py를 켜고 localhost:4173을 엽니다.
    3. 3나중에 보기: 위쪽 "실행 기록 열기"로 .jsonl 파일을 고르면 그 실행을 그대로 재생합니다.

    질문과 답, 실제로 이렇게 답했습니다

    에이전트를 평가할 때 돌린 질문 0개와 에이전트가 실제로 쓴 답입니다. 어떤 도구를 불렀는지와 자동 점검 결과를 함께 보여 줍니다. 이 화면에서는 새 질문을 할 수 없고, 내 컴퓨터에서 python src/agent.py "질문"으로 합니다.
