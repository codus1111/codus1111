## 1. 데이터 출처와 이용 조건 (2026-11-10 공공데이터포털 상세 페이지에서 직접 확인)

| [Gemini API 무료 구간](https://aistudio.google.com/docs/terms) | Google | 에이전트의 LLM 호출 | **무료 구간(Unpaid Services)은 입력·출력이 제품 개선에 쓰이고 사람이 읽을 수 있음**(약관, 2026-11-10 확인). "민감·기밀·개인정보를 넣지 말 것". 18세 이상. EEA·스위스·영국 사용자 대상 서비스로 공개하면 유료만 가능. 속도 한도는 공식 페이지에서 찾지 못해 AI Studio 화면에서 확인 |

- 날씨는 Open-Meteo의 재분석(ERA5 계열, 약 25km 격자) 값이다. 관측값이 아니며 대전 한 지점(36.35, 127.385)의 값으로 전 지역을 대표한다. 분석에 사용하기 전 이 점을 한계로 명시한다.
- 포트폴리오는 광고·구독이 없는 비상업적 용도다. 상업적으로 전환하면 유료 플랜이 필요하다. 출처 표기: "Weather data by Open-Meteo.com (CC BY 4.0)".
- 수집은 1회 호출(2025-12-01~2026-10-31)로 했고, 한도를 넘지 않는다.
- 보유근거: 대전광역시 공영자전거 타슈 이용약관. 데이터는 타슈 시스템에서 추출된 것이다.
- 수집 방식: 공공데이터포털의 공식 다운로드와 공식 OpenAPI만 사용한다.
- 약관과 조건은 바뀔 수 있으므로 API 신청 시점에 한 번 더 확인한다.

### 재식별 위험 점검 (2026-11-10 추가)
- 컬럼: 자전거번호, 대여·반납 일시(초 단위), 대여·반납 대여소 ID·명·좌표·주소, 이용시간, 이용거리. 이용자 ID·성별·연령은 없다.
- 준식별자: 시각(초 단위), 장소(아파트 단지 대여소), 자전거번호.
- 단독으로는 이용자를 알아보기 어렵지만, 결합·세분화 시 거주자의 이동 패턴이 추정될 여지가 있다. 개인정보보호법상 "다른 정보와 쉽게 결합하여 알아볼 수 있는" 정보에 해당하는지는 **조문 원문을 확인하지 못해 미확정**이다(아래 미확인 항목).
- 대응: 위 "소수 셀 억제", "집계 단위 공개", "개별 이용 기록 공개 금지"를 적용한다.

### 사용자 결정 필요

- [ ] 소수 셀 임계값(현재 제안값 10) 확정.

### Gemini 무료 구간 사용 조건 (2026-11-10)
- 에이전트 기본값은 Gemini 무료 구간이다. 입력이 학습·사람 검토에 쓰일 수 있으므로 **보내는 것은 사용자 질문과 `agent_tools.py`의 집계 결과(대여소·구간 단위, 이용 200건 미만 숨김, 상위 20곳 제한)뿐**이다. 원본 행·자전거번호·개인정보는 절대 넣지 않는다.
- 에이전트를 외부에 공개 서비스로 배포하지 않는다(로컬 데모만). 한도(429)는 한 번 재시도하고 우회하지 않는다.
- 모델 ID는 `.env`의 `GEMINI_MODEL`로 바꾼다. 무료 지원 모델 목록은 가격 페이지를 따른다.

### 지도 시각화 점검 (2026-11-11)
- 대시보드의 동네 지도는 **동(洞) 단위 합계**만 그린다. 개별 대여소 위치·이름과 이동 경로는 그리지 않는다.
- 소수 셀 억제: 대여소가 3곳 미만이거나 평일 시간대 이용이 200건 미만인 동은 뺀다. 시간은 출근·낮·퇴근 구간으로만 나눈다.
- 지도 타일 같은 외부 지도 서비스는 쓰지 않는다(약관·저장 제한 회피). 배경은 geoBoundaries 구 경계(CC BY 3.0) 파일 하나를 직접 그린 것이고, 점의 위치는 대여소 좌표의 동별 평균이다.
- 타슈 실시간 대여소 API(거치대 수·재고)는 키 신청 전이라 사용하지 않았다. 도입할 때는 응답 필드와 호출 제한을 확인하고 이 문서를 갱신한다.

## 3. 데이터 품질 메모 (2026-11-10 확인)

- 기간 2025-12-01 ~ 2026-10-31, 총 8,008,537행, 19컬럼, 대여 기준 대여소 1,406곳, 자전거 6,406대
- 월별 CSV의 인코딩이 섞여 있음(UTF-8 6개, CP949 5개) → 파일마다 감지해서 읽기
- 노이즈: 관제센터 대여 2.5%·반납 2.7%, 이용시간 0분 이하 2.0%, 180분 이상 0.35%, 같은 대여소 대여·반납 8.2%
- 문서가 밝히는 한계: 관제센터 대여소는 관리자의 강제 반납 처리 건
- 이 데이터에는 재고가 아니라 이동 기록만 있다. "부족"은 순유출 누적으로 추정하고, 실시간 재고 API는 보조로만 쓴다.
