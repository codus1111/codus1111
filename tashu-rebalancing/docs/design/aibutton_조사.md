# AI 버튼 현장 조사 (P13-1, 2026-11-26)

버튼을 넣기 전에 화면에서 건드리면 깨질 곳(벽 속 수도관)을 적는다.

## 대상 화면
- **붙일 곳:** `agent-dashboard/index.html` (에이전트 관제 화면, 단일 HTML 약 112KB). 스크립트 **있음**이므로 원래 기능은 그대로 두고 버튼만 더한다.
- 다른 화면 `reports/dashboard.html`은 `src/make_dashboard.py`가 `src/dashboard_template.html`로 **다시 만드는 파일**이라 직접 고치면 다음 생성 때 사라진다. 이번에는 건드리지 않는다.
- 외부 배포는 아직 없음(내 컴퓨터에서 파일로 열거나 `serve.py`로 127.0.0.1:4173).
- 어제 심사 기준 `review_1125.md`: **없음**. 기준 여섯 개는 이 프로젝트 규칙(CLAUDE.md 절대 규칙, docs/COMPLIANCE.md)으로 새로 만든다.

## 조심할 곳
| 위치 | 무엇 | 버튼에 주는 영향 | 대응 |
|---|---|---|---|
| `index.html` 1109–1111행 | `document`에 `dragover`/`drop` 처리기가 있고 `drop`에서 항상 `preventDefault()` 후 파일을 실행 기록으로 읽음 | 입력 칸에 글을 끌어다 놓으면 막히고, 파일을 놓으면 실행 기록으로 열림 | 입력 칸에서 파일이 아닌 끌어 놓기는 `stopPropagation`으로 원래 처리기에 안 가게 함 |
| 1213행 | 탭 버튼에서 ←/→ 키로 탭 이동 | 탭에 포커스가 있을 때만 동작. 입력 칸 타이핑에는 영향 없음 | 그대로 둠 |
| 1218행 | `hashchange`로 탭 전환 | 새 패널이 링크(#)를 쓰면 탭이 바뀔 수 있음 | 새 패널은 `#` 링크를 쓰지 않음 |
| 곳곳 `innerHTML` | 기존 코드가 템플릿을 innerHTML로 넣음 | 붙여 넣은 글을 innerHTML로 넣으면 스크립트 주입 위험 | 새 코드는 사용자 글을 **textContent/value로만** 다룸 |
| 11행 | Tailwind CDN | 새 클래스는 기존에 쓰던 것과 `panel`/`btn`/`chip` 같은 자체 클래스 위주로 | 새 CSS는 최소로 |
| 클립보드 | `navigator.clipboard`는 보안 컨텍스트(https, localhost)에서만 확실 | `file://`로 열면 실패할 수 있음 | 실패 시 글을 선택 상태로 보여 주고 Ctrl+C 안내(대체 경로) |
| `serve.py` | `index.html`과 기록 파일만 내줌 | 버튼은 서버가 필요 없음 | 서버는 고치지 않음 |
| 규칙 10(외부 LLM에는 집계·요약만) | 버튼이 만든 글을 사용자가 Claude 새 채팅에 붙여 넣음 = 외부 전송 | 행 단위 원본·키가 섞이면 규칙 위반 | 복사 전에 키·토큰처럼 보이는 문자열을 화면 안에서 먼저 찾아 막음, 안내 문구 표시 |

## 결론
`index.html` 한 파일에, 위쪽 "데이터" 막대 바로 위에 접히는 패널 하나를 더한다. 기존 처리기는 고치지 않고, 새 입력 칸에서만 끌어 놓기를 따로 처리한다.
